## Local checks

Run `python -m pytest -q` with the project's development dependencies and Node.js
on PATH. The JavaScript component checks can also be run with
`node tests/attorney_worksheet.cjs` when Playwright and Chrome are available.
Those DOM checks use a small jQuery event bridge and do not replace live
docassemble validation or save/resume testing.
